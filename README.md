# Мясорубка 🥩

Исходный код системы для [Мясорубки](https://t.me/myasorubk4)

Именно системы, а не бота, так как все распредлено по независимым компонентам:

- 👥 **Public Bot** — основной бот для работы с пользователями: прием заявок на участие
- 🎛 **Admin Bot** — бот для администраторов: проверка и верификация пользователей, их проектов
- 📺 **Channel Bot** — бот для работы с каналом: публикация батлов, подведение итогов голосования
- 🫜 **Redis** - хранение состояний пользователей, связь между компонентами
- 🐘 **PostgreSQL** - база данных

## ⚒️ Стек

- **Язык:** Python 3.11+
- **Telegram Bot API:** aiogram 3.x
- **База данных:** PostgreSQL
- **ORM / Запросы:** SQLAlchemy
- **Кэш и шина событий:** Redis

## 🚀 Быстрый запуск

### 1. Переменные окружения

Создайте файл `.env` в корне проекта по примеру [`.env.example`](.env.example). Затем заполните все требуемые поля

### 2. Запуск системы

```bash
 docker compose -f 'docker-compose.yml' up -d --build
```
